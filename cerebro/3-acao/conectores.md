# Conectores

Os "braços" do cérebro: aplicativos que o Claude consegue ler e onde consegue agir.

| Conector | Lê para a memória | Age por mim |
|---|---|---|
| **Notion** | páginas editadas no dia, roteiros, bases | cria e atualiza páginas, roteiros, briefings |
| **Gmail** | e-mails importantes do dia | rascunhos de resposta |
| **Google Agenda** | reuniões e compromissos do dia | cria e move eventos |
| **CarrosseIA** | | gera carrosséis a partir de roteiro (ver [[padrao-carrosseis]]) |
| **vidIQ** | números do YouTube/Instagram, transcrições | pesquisa de títulos, ganchos, tendências |
| **Vercel** (CLI no PC) | | publica sites (ver [[projeto-plataforma-comunidade]]) |
| **GitHub** (repositório VERTICE) | o próprio cérebro | salva memória nova (commit) |

Quem usa os conectores para alimentar o cérebro: [[rotina-intake-diario]].
