Vêm junto com o Claude Code / app desktop.

Skill | Para que serve

`code-review` | Revisar código atrás de bugs

`simplify` | Limpar e simplificar código alterado

`security-review` | Revisão de segurança

`init` | Criar o arquivo [CLAUDE.md](http://CLAUDE.md) de um projeto

`run` | Rodar o app do projeto para ver funcionando

`loop` | Repetir uma tarefa em intervalo (ex.: a cada 5 min)

`schedule` | Agendar agentes na nuvem (rotinas)

`update-config` | Mudar configurações e automações (hooks)

`keybindings-help` | Personalizar atalhos de teclado

`fewer-permission-prompts` | Reduzir pedidos de permissão

`claude-api` | Referência da API da Anthropic

`workflow-authoring` | Escrever workflows com vários agentes

`plugin-authoring` | Criar mods/plugins para o Claude Code

`dataviz` | Gráficos e dashboards

`artifact-design` / `artifact-diagramming` / `artifact-capabilities` | Criar páginas (Artifacts) publicadas no [claude.ai](http://claude.ai)
