# Aprendizados

Lições que valem para o futuro. Quando algo der errado e for resolvido, registrar aqui em uma linha, com link para o detalhe.

- **Carrossel viral é design + roteiro:** 1080×1440, leitura em F, contraste alto e estrutura de 10 slides com loop aberto valem mais que enfeite. Ver [[padrao-carrosseis]].
- **Print de slide:** tirar screenshot por área (`clip`) no Edge via Playwright; screenshot de elemento corta.
- **Site vende pela confiança:** sem cara de template, tipografia de agência e nada de prova social inventada. Ver [[padrao-sites-premium]].
- **Windows + `&` no nome da pasta** quebra npm/npx. Rodar as ferramentas direto pelo `node`.
- **Skills instaladas são cópias:** editar a fonte não basta, tem que recopiar. Ver [[skills]].
- **Instagram muda a API sem aviso:** manter anotado quais endpoints ainda funcionam. Ver [[projeto-salvos-instagram]].
- **Automação pela assinatura** (claude.exe + setup-token) evita pagar API separada.
- **Economia de créditos:** a partir de 60% do uso semanal, usar `/compact`.
- **Borda de corte não se estima pela cadência:** gerar tempo por palavra (faster-whisper `medium`) e conferir no arquivo renderizado. Ver [[padrao-video-cortes]].
- **SFX sintetizado fica ruim** e SFX bruto estoura a mix: usar a biblioteca com `gain_db`. Ver [[padrao-video-sfx]].
