Bem-vindo ao seu segundo cérebro. Cada ponto do grafo é uma nota, e cada linha é uma ligação escrita dentro de uma nota com colchetes duplos.

## Como usar
- **Clique num ponto** para abrir a nota aqui do lado. Passe o mouse para ver as conexões acenderem.
- **Busque** com Ctrl K (⌘ K no Mac). Acentos não importam. Use `#tag` ou `tipo:projeto` para filtrar.
- **Ligue ideias** digitando `[[` no editor e escolhendo uma nota. Se ela ainda não existir, o link fica tracejado e vira uma *ideia pendente* que você cria depois com um clique.
- **Vizinhança**: o botão de alvo no topo da nota mostra só o que está ligado a ela, com 1, 2 ou 3 saltos.
- **Mencionada em** mostra quem aponta para a nota. **Menções sem link** acha textos que citam o título sem ligar e cria o link com um clique.
- **Perguntar** usa a IA para responder a partir das suas notas, citando cada fonte.
- **Diário** (tecla D) cria a nota do dia. **Nota aleatória** (tecla R) ajuda a reencontrar ideias esquecidas.
- No menu ⋯ você importa arquivos `.md` do Obsidian e exporta tudo de volta como `.zip`.

## Como o grafo se organiza
O grafo agrupa as notas por **tema**: notas muito ligadas entre si formam uma região, com o nome da nota central. Cada tema tem um **mapa** (pontos dourados), uma nota-índice que explica o assunto e liga às notas dele. Os mapas se ligam ao núcleo, o [[Segundo Cérebro]].

Para ver um tema de perto, clique no nome dele em **Temas**, na barra lateral.

## Por onde começar
Abra o [[Segundo Cérebro]] e siga para o mapa que mais te interessa.

Todas estas notas têm a tag exemplo. Quando quiser começar do zero, use **⋯ → Remover notas de exemplo**.
