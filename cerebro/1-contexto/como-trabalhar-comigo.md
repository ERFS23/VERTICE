# Como trabalhar comigo

Preferências do [[elias|Elias]] para qualquer conversa.

## Idioma e ritmo

- **Sempre português do Brasil.** Não falo inglês (pedido explícito em 25/09/2026).
- Passo a passo guiado, **um passo por vez**, com cliques concretos.
- Posso cortar escopo no meio de uma tarefa: não adiantar fases seguintes.
- Quero o resultado **entregue no chat**, não só salvo em disco.

## Segurança

- Segredos (senhas, tokens) **eu mesmo digito** nos scripts. Nunca pedir para colar no chat.

## Economia de créditos

- No começo de cada conversa, checar o uso semanal. Se estiver em **60% ou mais**, só me **lembrar** de usar `/compact`. Nunca executar sozinho. Avisar no máximo uma vez por conversa.

## Dicas do meu PC (Windows)

- Colar com Ctrl+V em terminais/getpass falha nesta máquina. Os scripts leem da área de transferência (copiar e apertar Enter).
- O terminal do app não copia para a área de transferência do Windows. Usar a janela normal do PowerShell.
- `python3` no Git Bash é o atalho falso da Microsoft Store. Usar `python`.
- Pasta com `&` no nome quebra `npm`/`npx`. Rodar as ferramentas direto pelo `node` (ver [[aprendizados]]).
